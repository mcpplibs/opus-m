# Using mcpplibs.mwrap.opus

`import mcpplibs.mwrap.opus;` declares the API of libopus 1.6.1, opusfile 0.12 and libogg 1.3.6 as their headers do. Types and functions are the upstream globals, the very same entities as the headers', so a translation unit may include the headers too (through `<mwrap/opus/macros.hpp>`, see below). The libraries are `compat.opus` 1.6.1, `compat.opusfile` 0.12 and `compat.ogg` 1.3.6, built from the same release tarballs.

## Modules

| Module | What it holds |
|---|---|
| `mcpplibs.mwrap.opus` | libopus: the 13 types (`OpusEncoder`, `OpusDecoder`, `OpusMSEncoder`, `OpusMSDecoder`, `OpusProjectionEncoder`, `OpusProjectionDecoder`, `OpusRepacketizer`, `OpusDREDDecoder`, `OpusDRED`, `opus_int16` … `opus_uint32`) and 87 functions of `<opus.h>`, `<opus_multistream.h>`, `<opus_projection.h>`, `<opus_defines.h>` and `<opus_types.h>`; re-exports the three modules below |
| `mcpplibs.mwrap.opus.file` | opusfile: the 10 types (`OggOpusFile`, `OpusHead`, `OpusTags`, `OpusPictureTag`, `OpusFileCallbacks`, `op_read_func`, `op_seek_func`, `op_tell_func`, `op_close_func`, `op_decode_cb_func`) and 54 functions of `<opusfile.h>` |
| `mcpplibs.mwrap.opus.ogg` | libogg: the 12 types (`ogg_page`, `ogg_packet`, `ogg_stream_state`, `ogg_sync_state`, `oggpack_buffer`, `ogg_iovec_t`, `ogg_int16_t` … `ogg_uint64_t`) and 71 functions of `<ogg/ogg.h>` and `<ogg/os_types.h>` |
| `mcpplibs.mwrap.opus.macros` | the macros, in `mcpplibs::mwrap::opus::macros` |

The public headers are the ones upstream installs. `<opus_custom.h>` is installed only by a custom-modes build, which `compat.opus` is not. libogg's `<ogg/config_types.h>` is generated by `compat.ogg` and declares the `ogg_int*_t` typedefs that `<ogg/os_types.h>` declares itself on Windows and Apple.

### The API in one paragraph

`opus_encoder_create(rate, channels, application, &error)` makes an encoder for 8, 12, 16, 24 or 48 kHz and one or two channels. `opus_encode` / `opus_encode24` / `opus_encode_float` turn one frame (2.5 to 120 ms) of interleaved PCM into a packet. `opus_decode*` turn a packet back into PCM, or conceal a lost one (a null packet), or recover it from the next packet's in-band FEC (`decode_fec = 1`). `opus_*_ctl` set and query the codec (bitrate, complexity, signal type, bandwidth, FEC, DTX, gain, the final range …). The `opus_multistream_*` functions carry up to 255 channels in one packet (`opus_multistream_surround_encoder_create` picks the streams for 5.1 and friends), and `opus_projection_*` carries ambisonics. `opus_packet_*` parse packets without decoding them, and `OpusRepacketizer` merges and splits them. Ogg Opus files (RFC 7845) are pages of an Ogg stream: libogg's `ogg_stream_packetin` / `ogg_stream_pageout` write them and `ogg_sync_*` read pages back. opusfile's `op_open_file` / `op_open_memory` / `op_open_callbacks` open one, with `op_head` and `op_tags` for its headers, `op_pcm_total` for its length after pre-skip and end trimming, `op_pcm_seek` for sample-accurate seeking, and `op_read*` for 16-bit or float PCM at 48 kHz, chained links included.

### Not exported: libopusurl

opusfile's tarball also builds libopusurl (`src/http.c`: HTTP and HTTPS streams over OpenSSL). `compat.opusfile` does not, so its declarations in `<opusfile.h>` are not exported: `OpusServerInfo`, `opus_server_info_init` / `_clear`, `op_url_stream_create` / `_vcreate`, `op_open_url` / `op_vopen_url`, `op_test_url` / `op_vtest_url`, and their 16 macros (`OP_HTTP_PROXY_HOST`, `OP_SSL_SKIP_CERTIFICATE_CHECK`, `OP_GET_SERVER_INFO`, `OP_URL_OPT` …).

### What the build has, and what it does not

- Upstream's default floating-point build: the float API, hardening on, assertions off.
- Deep PLC, DRED, OSCE and QEXT are off, as upstream's defaults have them. The DRED API is still declared and defined: `opus_dred_alloc` reports `OPUS_UNIMPLEMENTED`, and so do `OPUS_SET_DRED_DURATION`, `OPUS_SET_OSCE_BWE`, `OPUS_SET_QEXT` and `OPUS_SET_DNN_BLOB`.
- Plain C: neither the x86 intrinsics (per-file `-msse4.1` / `-mavx2`) nor the NEON files, and no run-time CPU detection.

### Upstream behavior worth knowing

- `opus_tags_copy` reads the source's vendor string, which `opus_tags_init` leaves null. In opusfile 0.12, copying freshly initialised tags dereferences that null pointer. Copy tags that were parsed, or give them a vendor first.
- `ogg_page_bos` and `ogg_page_eos` return the header-type flag (`0x02`, `0x04`), not 1.
- `opus_tagncompare(name, len, comment)` requires the comment's `=` right after `len` characters.

## Macros

A named module cannot export a macro. `mcpplibs::mwrap::opus::macros` holds the mappings under their original names. With `using namespace mcpplibs::mwrap::opus::macros;`, code reads as it does with the headers.

- **Constants** as `inline constexpr int`: the error codes (`OPUS_OK` … `OPUS_ALLOC_FAIL`), `OPUS_AUTO`, `OPUS_BITRATE_MAX`, the applications, signals, bandwidths and frame sizes, `OPUS_RESET_STATE`, every `*_REQUEST` (49 of `<opus_defines.h>`, 2 of multistream, 3 of projection), and opusfile's `OP_FALSE` … `OP_EBADTIMESTAMP`, `OPUS_CHANNEL_COUNT_MAX`, `OP_PIC_FORMAT_*`, `OP_DEC_FORMAT_*`, `OP_DEC_USE_DEFAULT` and the `OP_*_GAIN` types. That is 115 in all.
- **Type aliases** for the 6 type macros of `<opus_types.h>`: `opus_int` (`int`) and `opus_uint` (`unsigned int`) are always macros. `opus_int8`, `opus_uint8`, `opus_int64` and `opus_uint64` are macros (`signed char`, `long long` …) that the header replaces with `<stdint.h>` typedefs when it decides `<stdint.h>` is there. That depends on the compiler and on what was included first, so they are aliases here, of the type the module saw.
- **CTL requests** for the 54 CTL macros. `OPUS_SET_BITRATE(x)` expands to `OPUS_SET_BITRATE_REQUEST, opus_check_int(x)`, the trailing arguments of the variadic `opus_encoder_ctl`. Here `OPUS_SET_BITRATE(x)` is a constexpr function returning `ctl_request<opus_int32>{OPUS_SET_BITRATE_REQUEST, x}`. Each argument has the type the macro's check requires: `opus_int32` for `opus_check_int`, `opus_int32 *` for `opus_check_int_ptr`, `opus_uint32 *`, `const void *`, `OpusEncoder **`, `OpusDecoder **`, and `unsigned char *` for the demixing matrix. Each of the 7 `*_ctl` functions (`opus_encoder_ctl`, `opus_decoder_ctl`, `opus_dred_decoder_ctl`, the multistream and projection ones) has an overload in the same namespace that takes a `ctl_request` and makes the variadic call. Argument-dependent lookup finds it, so `opus_encoder_ctl(enc, OPUS_SET_BITRATE(64000))` and `opus_decoder_ctl(dec, OPUS_GET_FINAL_RANGE(&range))` work even without the using-directive. A constant request such as `OPUS_RESET_STATE` goes straight to the variadic function.

Each mapping is checked against the raw headers in [tests/macros_mix_test.cpp](../tests/macros_mix_test.cpp): every constant's type and value, every alias's type, and every CTL function's request and arguments against the comma list its macro produces (as a tuple of the same types and values).

### What stays a macro

These stay macros in `<mwrap/opus/macros.hpp>`, which includes `<stdint.h>`, `<opus.h>`, `<opus_multistream.h>`, `<opus_projection.h>` and `<opusfile.h>` in the order every module of this package does:

| Macros | Why |
|---|---|
| `OPUS_EXPORT`, `OPUS_WARN_UNUSED_RESULT`, `OPUS_ARG_NONNULL`, `OP_WARN_UNUSED_RESULT`, `OP_ARG_NONNULL` | attributes of declarations |
| `OPUS_RESTRICT`, `OPUS_INLINE` | keyword spellings |
| `OPUS_GNUC_PREREQ`, `OP_GNUC_PREREQ` | compiler-version tests for `#if` |
| `OPUS_HAVE_OPUS_PROJECTION_H` | an empty feature test for `#ifdef` |
| `opus_check_int`, `opus_check_int_ptr`, `opus_check_uint_ptr`, `opus_check_uint8_ptr`, `opus_check_val16_ptr`, `opus_check_void_ptr`, `opus_check_encstate_ptr`, `opus_check_decstate_ptr` | the CTL macros' argument checks; the mapped CTL functions' parameter types do the same job |
| `_ogg_malloc`, `_ogg_calloc`, `_ogg_realloc`, `_ogg_free` | the allocator names of libogg's own sources |

Include the side header before the import, and include it rather than `<opus.h>` directly. It puts `<stdint.h>` first, so `<opus_types.h>` makes the same macro-or-typedef choice as in the modules. While a header macro is defined, it expands even inside a qualified name: `macros::OPUS_OK` reads as `macros::0`. Use the plain macro, or set it aside with `#pragma push_macro`. A function-like macro does not expand when its name is followed by `)`, so `(macros::OPUS_SET_BITRATE)(x)` is the mapped function beside the header's `OPUS_SET_BITRATE(x)`. Both pass the same request ([tests/header_mix_test.cpp](../tests/header_mix_test.cpp)). [tools/check_exports.py](../tools/check_exports.py) accounts for all 221 macros: 175 mapped, 22 kept, 16 libopusurl's and 8 include guards.

## Checks

- `mcpp test` runs five tests:
  - [tests/api_test.cpp](../tests/api_test.cpp) exercises the API through the module only. For libopus it covers CELT and SILK round trips (the signal-to-noise ratio, and the encoder's and decoder's final range after every packet), the 16-bit, 24-bit and float interfaces, FEC and concealment, CTLs through the mapped macros, states in caller memory, packet parsing and padding, the repacketizer, 5.1 multistream with its per-stream states, ambisonics with its demixing matrix, soft clipping, and DRED reporting `OPUS_UNIMPLEMENTED`. For libogg it covers the bit packers and pages through the sync layer. For opusfile it covers memory, callbacks and a file, OpusHead and OpusTags, R128 gains, a cover picture, chained links with their own channel counts, seeking, gain offsets, dithering and the decode callback;
  - [tests/macros_mix_test.cpp](../tests/macros_mix_test.cpp) (generated) checks every constant, alias and CTL function against the headers;
  - [tests/header_mix_test.cpp](../tests/header_mix_test.cpp) puts the headers beside the import: the same entities, both CTL spellings, and the attribute and keyword macros on declarations of one's own;
  - [tests/macros_test.cpp](../tests/macros_test.cpp) uses the macros module alone, at compile time;
  - [tests/link_test.cpp](../tests/link_test.cpp) (generated) takes the address of each of the 212 exported functions.
- `python3 tools/check_exports.py` checks that the sources are what [tools/gen_exports.py](../tools/gen_exports.py) writes from the pinned headers. It also checks that every declaration is exported (libopusurl's aside), that every macro is mapped, kept, libopusurl's or an include guard, and that every variadic `*_ctl` function has its overload.
- `python3 tools/run_conformance.py` runs RFC 8251's decoder test vectors through [examples/opus](../examples/opus). That is all twelve, at 48, 24, 16, 12 and 8 kHz, mono and stereo: 120 decodes. Each one checks the range decoder's final state against the encoder's after every packet, and each output passes libopus's own `opus_compare` against `testvectorNN.dec` or RFC 8251's alternative `testvectorNNm.dec`. Then the Ogg Opus tool encodes, describes and decodes a 48 kHz stereo and a 16 kHz mono WAV, and each decoded file must be exactly the input's length.
- `python3 tools/test_template.py` scaffolds the default template from an installed copy of the package, then builds and runs it.
